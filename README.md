# My dotfiles

This repository contains my personal dotfiles, which are configuration files for various applications and tools that I use on my computer. These dotfiles help me customize my environment and improve my productivity.


## Contents
- `.bashrc`: Configuration for the Bash shell, including aliases and environment variables.
- `.vimrc`: Configuration for the Vim text editor, including key mappings and plugins.
- `.gitconfig`: Configuration for Git, including user information and aliases.
- `.tmux.conf`: Configuration for the Tmux terminal multiplexer, including key bindings and appearance settings.
- `.zshrc`: Configuration for the Zsh shell, including plugins and themes.
- `.ideavimrc`: Configuration for the IdeaVim plugin in JetBrains IDEs, including key mappings and settings.
- `.bash_profile`: Configuration for the Bash shell, including environment variables and startup commands.
- `.env`: A file containing environment variables for various applications and tools.

- Neovim configuration: A directory containing configuration files for Neovim, including `init.vim` and various plugin configurations.
- JetBrains IDE configuration: A directory containing configuration files for JetBrains IDEs, including `idea` and `vscode` settings.
- Alacritty configuration: A directory containing configuration files for the Alacritty terminal emulator, including `alacritty.yml` and color schemes.
- Ranger configuration: A directory containing configuration files for the Ranger file manager, including `rc.conf` and `scope.sh`.
- Tmux configuration: A directory containing configuration files for Tmux, including `tmux.conf
` and `tmuxinator.yml`.
- Zsh configuration: A directory containing configuration files for the Zsh shell, including `z
shrc` and `ohmyzsh` plugins.
- Git configuration: A directory containing configuration files for Git, including `gitconfig` and `
gitignore`.
- IDE configuration: A directory containing configuration files for various IDEs, including `idea` and
    `vscode` settings.

## Usage
To use these dotfiles, you can clone this repository to your home directory and create symbolic links to the appropriate configuration files. For example, you can run the following commands in your terminal:

```bash
git clone
cd dotfiles
ln -s ~/dotfiles/.bashrc ~/.bashrc
ln -s ~/dotfiles/.vimrc ~/.vimrc
ln -s ~/dotfiles/.gitconfig ~/.gitconfig
ln -s ~/dotfiles/.tmux.conf ~/.tmux.conf
ln -s ~/dotfiles/.zshrc ~/.zshrc
ln -s ~/dotfiles/.ideavimrc ~/.ideavimrc
ln -s ~/dotfiles/.bash_profile ~/.bash_profile
ln -s ~/dotfiles/.env ~/.env
```
